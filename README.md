## 🛠️ Tech Stack

- **Frontend Framework**: React 19 + TypeScript + Vite 6
- **Styling & Design System**: Tailwind CSS v4 + Custom Glassmorphic & Aurora UI System + Lucide Icons
- **AI & LLM Layer**: Google Gemini SDK (`@google/genai`) with multi-model automatic failover + optional Groq (`LLaMA / GPT-OSS`) support

## 🚀 Getting Started Locally

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/teachbuddy-ai.git
cd teachbuddy-ai
```

<br />

### 2. Install Dependencies

```bash
npm install
```

<br />

### 3. Configure Environment Variables

Create a `.env` file in the project root and add your Google Gemini API key:

```env
GEMINI_API_KEY=your_google_gemini_api_key_here
VITE_GEMINI_API_KEY=your_google_gemini_api_key_here
```

<br />

### 4. Launch the Development Server

```bash
npm run dev
```

Open **http://localhost:3000** in your browser.

## 🌐 1-Click Deployment on Netlify

This repository is pre-configured with `netlify.toml`, `public/_redirects`, and `netlify/functions/api.mjs` so both the React SPA and `/api/*` AI endpoints work automatically:

1. Push this repository to your **GitHub** account.
2. Go to [Netlify](https://app.netlify.com/) -> **Add new site** -> **Import an existing project** and select your repository.
3. Verify the auto-detected build settings:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
   - **Functions directory**: `netlify/functions`
4. Open **Site configuration -> Environment variables** and add:
   - `GEMINI_API_KEY` = `your_google_gemini_api_key`
5. In the **Firebase Console -> Authentication -> Settings -> Authorized domains**, add your `.netlify.app` domain so Google Sign-In works seamlessly.
